# Images

This directory contains the graphical assets used throughout the **RAFS-VI (Real-Time Auditory Feedback System for the Visually Impaired)** repository.

The images document the system architecture and the implemented wearable prototype. They are referenced throughout the repository to illustrate the overall design, hardware integration, and physical implementation of the system.

# Architecture Figures

The `architecture/` directory contains illustrations describing the overall operation and hardware organization of RAFS-VI.

| Figure | Description |
|--------|-------------|
| **fig01_concept_of_operation.png** | High-level overview of the RAFS-VI processing pipeline, illustrating object detection, distance estimation, and spoken audio feedback. |
| **fig02_hardware_layout_sketch.png** | Hardware layout concept showing the proposed placement of the camera, embedded processor, power subsystem, audio output, and user interface components. |

# Naming Convention

Image filenames follow a consistent naming scheme to improve organization and simplify referencing throughout the repository.

Examples include:

- `fig01_concept_of_operation.png`
- `fig02_hardware_layout_sketch.png`
- `fig01_prototype_left_front_view.png`

This convention provides stable figure identifiers while remaining descriptive and easy to reference within documentation.
