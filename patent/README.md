# Patent

This directory contains the patent-related documentation associated with the **RAFS-VI (Real-Time Auditory Feedback System for Visual Impairment)** project.

The included document describes the intellectual property developed as part of the project, including the wearable system architecture, embedded hardware integration, monocular vision-based distance estimation methodology, and real-time auditory feedback mechanism.
